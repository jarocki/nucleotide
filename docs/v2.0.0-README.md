Short version: 2.0.0 stops selecting mid-token snippet fragments, stops
short anchored common words and bare numbers from attributing, requires a
snippet to be anchored where it lands in the URI, and stops signal-poor
actors from collapsing into one hash. On the Log4Shell capture the 88 false
UNIQUE rows from 1.0.0 become 1, and the two actors 1.0.0 mislabelled as
nuclei are `unknown`. What remains open is in ANALYSIS.md §4.
